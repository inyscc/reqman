# Spec Delta

## MODIFIED Requirements

### Requirement: 脚本 console 输出的收集与呈现

系统 SHALL 收集脚本执行期间产生的 console 输出并在界面上呈现，SHALL NOT 使其只能从应用日志中取得。每条输出 SHALL 标明产生它的阶段（前置 / 后置）与脚本层级（集合 / 目录 / 请求）。收集到的输出 SHALL 进入全局 Console 面板（spec: request-console），SHALL NOT 再由响应区的「脚本」页签承载——同一份输出不在两个地方各抄一遍；「脚本」页签只负责断言与脚本错误。集合运行器的请求明细例外：它是模态，开着时看不到底部抽屉，因此那份明细 SHALL 仍随断言列出该次请求的输出。

**结构化值 SHALL 以保留结构的形态收集**：对象、数组等值不得在收集阶段就被拼成字符串——全局 Console 需要据此提供逐层展开。字符串化只发生在呈现层。

每条输出 SHALL 按原文呈现：多行文本的换行与缩进 SHALL NOT 被折叠为一行；超长的单行 SHALL 在呈现区内折行，SHALL NOT 要求用户横向滚动才能读全。

**行尾符 SHALL 一律按换行呈现**：`\n`、`\r\n` 与孤立的 `\r` SHALL 产生同样的断行效果，SHALL NOT 因行尾符不同而挤成一行。

**结构化参数的文本形态 SHALL 保持紧凑单行，SHALL NOT 自动缩进展开**：对象、数组等结构化值一律以紧凑 JSON 单行呈现。需要缩进时由脚本自行序列化（例如 `JSON.stringify(value, null, 2)`），呈现层按原文排版。长结构的可读性 SHALL 由全局 Console 的逐层展开承担（spec: request-console），而不是由宿主改换文本形态。

输出超长被截断时，截断提示 SHALL 独立成行，SHALL NOT 拼接在被截断的文本末尾。

#### Scenario: 输出可见

- **WHEN** 脚本调用 console 输出一段文本后发送请求
- **THEN** 该文本出现在全局 Console 的时间线上

#### Scenario: 输出可区分来源

- **WHEN** 同一次发送中前置脚本与后置脚本各自产生输出
- **THEN** 面板中的输出可区分来自哪一段脚本

#### Scenario: 多行输出保留换行

- **WHEN** 脚本以一条 console 输出打印含换行的多行文本（例如带缩进的 JSON）
- **THEN** 面板按原文呈现该文本，换行与缩进均保留，不折叠为一行

#### Scenario: 不同行尾符都断行

- **WHEN** 一条输出里的文本使用 `\r\n` 或只有 `\r` 作为行尾
- **THEN** 面板在每一处行尾断行，与使用 `\n` 时一致

#### Scenario: 结构化值展开为多行

- **WHEN** 脚本打印一段带缩进的多行 JSON 文本（例如 `JSON.stringify(value, null, 2)` 的结果）
- **THEN** 面板按原文呈现该缩进形态，每个字段占一行，不再做二次格式化

#### Scenario: 短小的结构化值保持一行

- **WHEN** 脚本打印一个紧凑形态很短的对象（例如 `{a:1}`）
- **THEN** 面板以单行呈现它

#### Scenario: 长结构化值同样不自动缩进

- **WHEN** 脚本打印一个紧凑形态超出一行可读长度的对象或数组（例如整份响应体）
- **THEN** 面板仍以紧凑单行呈现并就地折行，不自动加缩进；层级由全局 Console 的展开树查看

#### Scenario: 脚本页签不再承载 console 输出

- **WHEN** 一次发送的脚本产生了输出，但没有断言也没有脚本错误
- **THEN** 输出只出现在全局 Console，响应区连「脚本」页签都不出现

#### Scenario: 运行器明细仍列出输出

- **WHEN** 用户在集合运行器里点开某一条请求的明细
- **THEN** 该次请求的 console 输出随断言一起列出（运行器是模态，此时看不到底部抽屉）

#### Scenario: 层级来源可辨

- **WHEN** 集合层与请求层脚本各输出一行
- **THEN** 两行都标明所属层级，用户能看出哪一行来自集合层

#### Scenario: 对象在全局 Console 里可展开

- **WHEN** 脚本打印一个对象，用户在全局 Console 里展开该条输出
- **THEN** 字段与取值逐层可见，而不是一段不可展开的 JSON 文本
