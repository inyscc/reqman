- [x] 2.2 实现 `item` 递归映射，保持层级归属与同级顺序。验证：单测对多层嵌套样本断言生成的树结构与顺序与源文档一致。
- [x] 2.3 实现 URL 映射：把对象形式的 `protocol/host/path/query/variable` 与字符串形式的 URL 归一化为内部扁平 URL 加参数表，保留禁用参数与路径变量取值。验证：单测断言含 `:id` 路径变量与禁用查询参数的样本映射后路径与启用状态正确；断言 v2.0 字符串 URL 与 v2.1 对象 URL 在等价输入下产出同一结果。
- [x] 2.4 实现请求体映射：无正文、raw（含语言识别）、表单、URL 编码表单、二进制；文件字段与二进制正文降级为「未选择文件」并保留描述，不读取源文档所指路径。验证：单测逐类型断言映射后的类型、内容与内容类型标记；断言不携带其他类型的残留内容；断言含文件引用的样本导入后该字段存在且未选择文件，且过程中未发生任何文件读取。
- [x] 2.5 实现认证与事件映射，覆盖集合、文件夹与请求三个层级：支持的类型映射为对应认证，不支持的类型降级为 `none` 并产生降级记录，`prerequest` / `test` 事件文本进入该层级实体的前后置脚本。验证：单测断言 basic / bearer / api_key 在各层级映射正确；断言 digest 等样本降级为 `none` 且记录中含层级与条目名；断言事件文本落在对应层级而非只落在请求层。
- [x] 2.6 实现变量值的映射：源文档的单一值同时写入初始值与当前值，secret 标记保持。验证：单测断言导入后变量的初始值与当前值相等且等于源值；断言 secret 变量两列均按 secret 处理且仍参与替换。
